## Rollback procedure

1. `git revert <deploy-commit>` or `git checkout <previous-tag>`
2. `npm run build`
3. `npm run test` to verify
4. Restart server: `npm run dev` or restart hosting service
5. Run smoke check: `GET /api/health` returns 200
